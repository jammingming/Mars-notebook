# 火星边界面的圆锥曲线模型（BS / MPB）

> 这一篇不是"某一篇文章的笔记"，而是把**边界拟合这件事本身**整理清楚：为什么 BS、MPB 都用同一族圆锥曲线，参数各是什么含义，谁家的数是多少，以及这套做法在哪里失效。

## 1. 模型形式

轴对称假设下（绕**光行差修正后**的 $X'$ 轴，$\alpha\approx4^\circ$），三维面退化成 $(X',\ \rho=\sqrt{Y'^2+Z'^2})$ 平面里的一条曲线：

$$r=\frac{L}{1+\epsilon\cos\theta},\qquad
r=\sqrt{(X'-x_F)^2+Y'^2+Z'^2},\qquad
\cos\theta=\frac{X'-x_F}{r}$$

直角坐标形式（Trotignon et al. 2006 原式）：

$$Y'^2+Z'^2-(\epsilon^2-1)(X'-x_F)^2+2\epsilon L\,(X'-x_F)-L^2=0$$

三个参数、三个可直接报数的几何量：

| 参数 | 含义 | 导出的观测量 |
|---|---|---|
| $L$ | 半通径（semi-latus rectum），尺寸 | — |
| $\epsilon$ | 离心率，张口程度 | 渐近马赫锥角 $\varrho$ |
| $x_F$ | 焦点沿轴的位移（等效障碍中心） | — |
| | | 日下点 $R_{ss}=x_F+\dfrac{L}{1+\epsilon}$ |
| | | 晨昏线 $R_{td}=\sqrt{L^2+(\epsilon^2-1)x_F^2+2\epsilon L x_F}$ |

法向有闭式：面函数 $F=r+\epsilon(X'-x_F)-L$，故

$$\nabla F=\hat{\boldsymbol r}+\epsilon\,\hat{\boldsymbol x}
\quad\Longrightarrow\quad
\boldsymbol n=\pm\frac{\hat{\boldsymbol r}+\epsilon\hat{\boldsymbol x}}{|\hat{\boldsymbol r}+\epsilon\hat{\boldsymbol x}|}$$

==这一点对 $\theta_{Bn}$ 极其重要：不需要对样条做数值微分，法向是解析的，而且 $\boldsymbol n$ 只**线性**依赖 $\epsilon$。==

## 2. 为什么是圆锥曲线

### 2.1 几何：二次 + 轴对称 = 圆锥曲线

- **顶点附近**：任何光滑旋转面在驻点邻域都是抛物面（$\rho^2\simeq2R\,(x_{nose}-x)$），二阶正好够；
- **远场**：二次曲线的渐近线是**直线**，正好对应马赫锥 / 磁尾的张开；三次以上没有这个性质；
- **中间**：$(x,\rho)$ 平面里带 $\rho^2$ 项的一般二次式，在轴对称+无交叉项约束下**就是**圆锥曲线——所以"用二次型"和"用圆锥曲线"是同一件事，不是两个选择。

于是这一族用 3 个参数同时管住了"钝头"和"张开"两端。

### 2.2 物理：$\epsilon$ 不是自由旋钮，它锁定马赫锥角

气体动力学里，激波远场必须渐近到**极限马赫锥**，$\varrho=\arcsin(1/M_s)$。而双曲线 $r=L/(1+\epsilon\cos\theta)$ 的渐近线与轴的夹角恰好是

$$\varrho=\arctan\sqrt{\epsilon^2-1}
\qquad\Longleftrightarrow\qquad
\epsilon=\frac{M_s}{\sqrt{M_s^2-1}}$$

- $\epsilon=1$ 就是 $M_s\to\infty$ 的抛物线极限，所以"火星激波近抛物线"是真实物理，不是巧合；
- $\epsilon=1.026\Rightarrow\varrho=12.9^\circ\Rightarrow M_s\approx4.5$，正是火星磁声马赫数的典型值；
- $M_s=3$–$8$ 只对应 $\epsilon=1.008$–$1.06$，**这就是为什么大家取 $\epsilon\approx1$ 都够用**（Halekas 2017 干脆固定 $\epsilon=1$）。

⚠ 但反演是**病态**的：$\Delta\varrho=\dfrac{\Delta\epsilon/\epsilon}{\sqrt{\epsilon^2-1}}$。$\epsilon=1.026\pm0.002$ 给出的 $\pm0.5^\circ$ 已经是乐观情形；$\epsilon\to1$ 时误差发散，**不要**从拟合出的 $\epsilon$ 反推马赫数当作独立测量。

### 2.3 工程：3 个参数才配得上"稀疏穿越"

- Phobos 2 只有远尾穿越、MGS 只有近行星穿越，**必须外推**——样条/多项式做不了这件事，圆锥曲线可以；
- 早期研究只有 11 次穿越（Russell 1977），3 参数已经是上限；
- 40 年文献都用同一形式，$(\epsilon,L,x_F)$ 可以**直接跨任务比较**；换成别的函数，数字就没法对话了。

### 2.4 为什么 BS 和 MPB 能共用一族

两者都是"超音速/超磁声流被一个钝体挡住"形成的**轴对称驻点面**，几何上同类，差别只在 $\epsilon$ 落在哪：

- **BS**：$\epsilon\gtrsim1$（双曲），远场接马赫锥；
- **MPB 日侧**：$\epsilon<1$（椭圆），是**闭合**的帽；
- **MPB 夜侧**：另一段 $\epsilon>1$，接磁尾。

所以不是"用同一条曲线"，而是"用同一族曲线、取不同成员"——MPB 必须**两段**圆锥（Trotignon 2006 正是这么做的，两段合起来能描述到 $x=-16\,R_M$）。

## 4. Trotignon et al. (2006) 做了什么
[Martian shock and magnetic pile-up boundary positions and shapes determined from the Phobos 2 and Mars Global Surveyor data sets: J. G. Trotignon](https://doi.org/10.1016/j.pss.2006.01.003)

- 数据：Phobos 2（等离子体波系统）+ MGS（MAG/ER），首次把两套数据合并；
- 边界点：**700 个 BS**（127 + 573）、**901 个 MPB**（41 + 860），SZA 覆盖比单任务好得多；
- 结果：BS 单条圆锥（$\epsilon=1.026$）；MPB 用**两段圆锥**（日侧一段、夜侧一段），从近行星一直描述到 $x=-16\,R_M$；
- 给出 $R_{ss}$、$R_{td}$ 与马赫锥角的解析表达式；
- 同时指出：早期各任务单独拟合的激波模型彼此一致，改进主要来自数据量与 SZA 覆盖。

> 说明：本文未见 PSS 全文，以上依据其 COSPAR 2006 摘要（[COSPAR2006-A-00975](https://meetings.copernicus.org/www.cosis.net/abstracts/COSPAR2006/00975/COSPAR2006-A-00975-1.pdf)）与 Simon Wedlund et al. (2022) 的汇总表。

## 5. Simon Wedlund et al. (2022) 做了什么
[A Fast Bow Shock Location Predictor-Estimator From 2D and 3D Analytical Models: C. Simon Wedlund](https://doi.org/10.1029/2021JA029942)

- 把 2D 极坐标圆锥与 3D 二次型两套公式写成可直接落地的形式：$R_{ss}$、$R_{td}$、**任意点法向**、predictor / predictor-corrector 两套自动识别算法；
- MAVEN 2014–2021 自动识别出 **14 929 次** BS 穿越（以准垂直为主），预测位置平均误差 **0.15 $R_p$**，加 MAG 修正后约 **0.05 $R_p$**；
- 用 3D 二次型研究 MY / $L_s$ / EUV 依赖，指出 MY32、MY35 与高 EUV 时 Y、Z 不对称可达可观量级（叠加在 crustal field 造成的南北不对称之上）；
- 结论性提醒：$\epsilon$ 在 MY27–MY33 之间围绕 1 变化不到 5%，多数年份是**椭圆**（只有 MY28–29 是双曲）——即"$\epsilon$ 略大于 1"并不是普遍规律。

## 6. 这套做法的边界（什么时候不能信）

1. **只有近驻点—晨昏线一段可信**。Nemec et al. (2020) 明确指出这类模型 "unreliable beyond the terminator"；本项目 2016-09-23 的穿越点在 $x=-0.76\,R_M$、SZA≈106°，正好在晨昏线之后，属于外推区。
2. **无法表达不对称**。$Y$/$Z$ 不对称、crustal field 造成的南北差，圆锥曲线一律抹平；要描述就得上 3D 二次型（Formisano 1979 用 99 个自由参数）。
3. **MPB 一条曲线不够**，必须分段；日侧与夜侧的物理机制本来就不同（压力平衡 vs 渐变的电离层–磁尾过渡）。
4. **单点定标只能定 $L$**。本项目只有一个穿越点，$\epsilon$、$x_F$ 是从 Trotignon 借来的形状，不是拟合出来的——正文措辞应写"按 Trotignon 形状、用本轨道穿越标定尺度"，不能写"拟合"。
5. **对 $\theta_{Bn}$ 反而不敏感**：$\boldsymbol n\propto\hat r+\epsilon\hat x$，把 $\epsilon$ 从 1.026 换成 Edberg 的 1.05，穿越点处法向只转约 $1^\circ$。所以形状借用的误差对 $\theta_{Bn}$ 结论影响很小，对**边界位置**（尤其远尾）影响大。
